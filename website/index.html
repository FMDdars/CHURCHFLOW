GOOD TO KNOW

Frequently asked
questions.

A few helpful details before you get started.

Does ChurchFlow work offline?

ChurchFlow is designed as an offline-first application. Online lyrics lookup and update checks need an internet connection, but your local presentation workflow is designed to remain available offline.

Which computers are supported?

The current published desktop builds are for Windows x64. Check the release notes for the requirements of each version.

Can I use more than one display?

ChurchFlow supports connected display workflows. The number of usable displays depends on your computer, graphics hardware and Windows display configuration.

Is NDI included?

NDI is an optional integration. The official NDI Runtime must be installed separately, and the feature should be tested with your production equipment before a live service.

How do I update ChurchFlow?

For the installed setup version, use the in-app update check when an update is published. You can also download the latest installer from this page. The portable version should be replaced with the latest build manually.
